Discovery / Acumen Academy

For this project, I chose Acumen Academy, an e-learning platform that offers online courses and training programmes focused on social engagement and leadership development.

During this phase, I learned how to:

  • analyse the strengths and weaknesses of the platform
  • evaluate usability
  • identify the target audience and competitors
  • create user personas and develop user journeys
  • identify obstacles and critical issues in user experience
The project represents the first phase in the design process of a digital platform. This approach has the function to identify objectives and define user needs.

Accessibility / Acumen Academy

This step, which is often overlooked but it is very important, focuses on making digital products easy to use for people with different abilities, including those with disabilities.

I learned how to:

  • develop user personas with different disabilities
  • develop customised user scenarios and user journeys
  • identify accessibility issues
  • find solutions to improve the experience of users with special needs and not
Thanks to this project, I discovered how to ensure that everyone, regardless of physical or cognitive limitations, can navigate, understand and interact with the platform effectively.

Wireframing / Acumen Academy

In this initial phase of designing a digital product, it is essential to create the skeleton of the website through wireframes and identify the paths that users follow to complete specific activities.

I learned how to:

  • create 5 wireframes of the platform's pages, which helped me visualise and clearly communicate the structure of the website
  • design wireflows that allowed me to understand how users navigate and identify potential problems
This design is important for both desktop and mobile versions, ensuring that the platform is responsive on different devices.

User Test / Acumen Academy

User testing is a fundamental technique for understanding how intuitive, effective and satisfying an interface is for users.

In this project, I learned how to:

  • conduct a usability test
  • collect real data on user behaviour while completing five specific tasks
  • observe how users interacted with the product
  • identify any difficulties during the process
  • find solutions and apply them to prototypes
This data helped me identify areas for improvement to make the user experience simpler and seamless.
